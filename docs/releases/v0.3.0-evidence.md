## Implemented verification coverage

The v0.3.0 test suite now covers:

- Zod validation, stable Block ids/order, the 2 MiB representation limit, and
  safe public serialization;
- TXT paragraphs, Markdown headings/lists/fenced code, PDF page provenance,
  blank-versus-image classification, and DOCX headings/lists/tables/image
  references;
- deterministic Unicode/control/whitespace cleaning, empty content,
  near-empty review, and conservative repeated PDF header/footer removal;
- structure-aware list/table boundaries and exact Block/heading/page
  provenance across character limits;
- idempotent migration from a v0.2.9-style database;
- new-upload publication gating, low-quality non-publication, embedding
  failure, shadow reprocessing, publication compensation, deletion
  compensation, and database/index convergence;
- authenticated document detail, Block pagination, optional chunk provenance,
  and idempotent reprocessing;
- bilingual desktop/mobile document detail expectations for quality, Block,
  stage, and chunk inspection.

Two independent reviews completed. Their findings covering index/SQLite
publication ordering, guarded shadow recovery, unknown index convergence,
blank and image-only formats, uncertain page furniture, oversized structures,
Chunk provenance, error presentation, and stale detail requests were fixed.

## Known limits

- DOCX list numbering style is not reconstructed beyond reliable list
  membership; vertical table merges require review.
- PDF reading order is limited to deterministic order exposed by the current
  text parser; no layout inference is invented.
- Block payloads and processing history add SQLite storage; binary source files
  are not duplicated.
- Review-required and rejected documents cannot be force-published in v0.3.0.
- Processing is synchronous and explicitly retried; background recovery and
  scheduled refresh remain v0.3.4 work.
