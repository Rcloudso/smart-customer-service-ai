## Dependency residual risk

The unused direct `xlsx` dependency and the `bcrypt` install-chain findings
were removed. `uuid`, `express-rate-limit`, and React Router were upgraded.
The final official-registry audit reports two high-severity package nodes from
one React Router RSC/server-action advisory (`GHSA-qwww-vcr4-c8h2`).
ResolveWeave uses only Vite `BrowserRouter`, static `Routes`, `Route`,
`Navigate`, `Outlet`, `useNavigate`, and `useLocation`; it has no React Router
SSR/RSC runtime, actions, loaders, server hydration, or user-controlled
navigation target. The advisory is therefore not reachable in this deployment
architecture, but remains tracked until an upstream release fixes both the SPA
redirect advisories and the newer RSC advisory simultaneously.
