## Threat Model

Protect anonymous customer conversations, administrator identity, provider credentials, deployment secrets, knowledge provenance, export consumers, and optional OCR availability across public HTTP, admin-only APIs, private model/OCR services, SQLite, and browser rendering boundaries.

### Assets

- Administrator credentials and JWT signing secret
- Provider API credentials and deployment-owned endpoints
- Customer conversations and knowledge-source provenance
- SQLite integrity and retrieval-index consistency
- Application and optional OCR service availability

### Trust Boundaries

- Anonymous browser to public chat and FAQ APIs
- Administrator browser to authenticated admin APIs
- Node service to external model and embedding providers
- Node service to token-authenticated OCR worker
- Untrusted Markdown and CSV data to browser/spreadsheet consumers
- Persistent deployment configuration to environment-managed identity

### Attacker Capabilities

- Send repeated IPv4 or IPv6 public requests and adversarial chat/FAQ input
- Cause administrators to ingest attacker-influenced documents or export stored text
- Submit malformed or resource-intensive supported OCR sources after obtaining the admin ingestion path
- Know historical repository-published default credentials on an upgraded persistent deployment

### Security Objectives

- Fail closed on missing secrets and authentication
- Keep provider destinations deployment-owned and bind credential reuse to the same endpoint
- Bound public request concurrency, pagination, stream bytes, document complexity, and result size
- Prevent stale privileged credentials, CSV formulas, browser image beacons, and public persistence metadata exposure
- Preserve compatibility and deterministic no-key operation while hardening optional services

### Assumptions

- ResolveWeave currently supports one environment-managed administrator account.
- The Compose deployment or an equivalent supervisor restarts an OCR worker after forced timeout exit.
- SQLite remains the authoritative store and the OCR worker is not exposed directly to the public internet.
